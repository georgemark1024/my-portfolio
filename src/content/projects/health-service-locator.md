## Project Overview

A lightweight, offline-accessible system that helps Kenyan citizens locate nearby health facilities e.g. hospitals, pharmacies and laboratories using any mobile phone—no internet or smartphone required.

## Key Achievements

- Queried Google Maps API to return health facilities close to the user
- Utilised Africa's Talking USSD and SMS API for mobile communication.
- Simplifying complex task flows into simple menu interactions

## Technologies Used

- **Backend**: Node.js
